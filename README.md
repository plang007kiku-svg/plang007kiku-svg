## 🎓 Threat Intelligence Concepts

### What is an IoC (Indicator of Compromise)?

An IoC is a piece of evidence that a system has been breached or compromised by an attacker.

- 🔗 **Domains** → Malicious C2 infrastructure
- 🔢 **IP Addresses** → Attacker command servers
- 📁 **File Hashes** → Malware signatures (MD5, SHA256)
- ✉️ **Email Addresses** → Phishing campaigns
- 🌐 **URLs** → Malicious web resources

### What is MITRE ATT&CK?

A global knowledge base of adversary tactics & techniques based on real-world observations.

- 🔵 **14 Tactics** → Stages of an attack
- 🔷 **600+ Techniques** → Specific methods used
- 📊 **Heatmap** → Which tactics are most active
- 🎯 **Correlation** → Link threats to tactics

### What is CVSS Score?

A metric for rating the severity of security vulnerabilities (0-10 scale).

- **9.0-10.0** 🔴 **CRITICAL** → Needs immediate patching
- **7.0-8.9** 🟠 **HIGH** → Patch within days/weeks
- **5.0-6.9** 🟡 **MEDIUM** → Plan remediation
- **0-4.9** 🟢 **LOW** → Monitor, may not need patching
